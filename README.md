# Blockscout for Golem Base L3s

Blockchain Explorer for inspecting and analyzing Golem Base L3 Chains.

*Note:* This is a fork of [Blockscout](https://github.com/blockscout/blockscout)

This fork extends the Blockscout to support Golem Base specific features, like tracking Entities.

## Running locally

See [development setup](./docs/development-setup.md) and [upstream docs](https://docs.blockscout.com/).

See also [Compose files](https://github.com/Golem-Base/blockscout-compose-files) for easy container-based solution.
